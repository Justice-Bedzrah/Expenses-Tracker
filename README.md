# 💰 Dynamic Expense Tracker

A clean, responsive web application designed to help users track income, manage expenses, and monitor their real-time net balance with local persistence.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Tech Stack](https://img.shields.io/badge/tech-HTML5%20%7C%20CSS3%20%7C%20JS%20ES6-yellow)

---

## 🌟 Key Features

- Real-Time Financial Calculation: Automatically updates total income, total expenses, and remaining net balance upon transaction entry.
- Dynamic DOM Manipulation: Adds and removes transaction records instantly without page reloads.
- Persistent Data Storage: Uses browser localStorage to save user records across sessions.
- Input Validation & Feedback: Validates form inputs before execution to ensure clean financial entries.
- Responsive Interface: Optimized layout for seamless accessibility on both mobile and desktop screens.

---

## 🛠️ Tech Stack

- HTML5: Semantic structural layout and accessibility.
- CSS3: Custom styling, Flexbox/Grid layouts, dynamic status indicators.
- JavaScript (ES6): Array methods (.filter(), .reduce()), event handling, DOM nodes, localStorage API.
